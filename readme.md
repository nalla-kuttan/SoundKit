# Sound Kit: Cyber-Glass Edition 🎹✨

A premium, interactive drum and guitar kit web application featuring a modern **Cyber-Glass** design and high-performance audio engine.

![Final App State](https://raw.githubusercontent.com/nalla-kuttan/SoundKit/main/final_verification_sound_kit.png)

## 🌟 Key Features

- **Cyber-Glass Aesthetics**: Stunning dark-mode UI with glassmorphism, neon glows, and dynamic wave animations.
- **Unified Engine**: Seamlessly switch between **Drums** and **Guitar** without reloading the page.
- **High-Performance Audio**: Built with optimized HTML5 Audio logic for low-latency playback and polyphony.
- **Master Volume Control**: Global gain control to fine-tune your sound.
- **Real-time Visualizer**: A wave-based visualizer that pulses in sync with your beats.

## 🚀 Getting Started

### Prerequisites

To hear the sound, you must run the application through a **local server**. Modern browsers block audio requests from the `file://` protocol for security reasons.

### Running Locally

1. **Open your terminal** in the project directory:
   ```bash
   cd "/Users/Shared/Portfolio itens/SoundKit"
   ```

2. **Start a local Python server**:
   ```bash
   python3 -m http.server 8000
   ```

3. **Open your browser** and visit:
   [http://localhost:8000](http://localhost:8000)

## ⌨️ Controls

### Drum Kit
- `w`: Tom 1
- `a`: Tom 2
- `s`: Tom 3
- `d`: Tom 4
- `j`: Snare
- `k`: Crash
- `l`: Kick

### Guitar Kit
- `w`: Chord 1 (Em)
- `a`: Chord 2 (Am)
- `s`: Chord 3 (C)
- `d`: Chord 4 (G)
- `j`: Chord 5 (D)
- `k`: Chord 6 (Bm)
